# Animate Anything with Sheriyans

This repository is a collection of beginner-friendly examples for various web animation libraries and techniques. Each folder contains a standalone example demonstrating the basics of a specific framework.

## Introduction

This repository is designed for learning and experimenting with different web animation libraries. Each directory is a self-contained project that you can open and explore.

## Frameworks and Examples

Here's a breakdown of the examples included in this repository:

### 1. Basic CSS Animations

-   **Folder:** `animation/`
-   **Description:** This example demonstrates fundamental CSS animations using `@keyframes`. It includes simple animations like moving a box and pseudo-element styling.
-   **How to use:** Open the `animation/index.html` file in your web browser.

### 2. GSAP (GreenSock Animation Platform)

-   **Folder:** `GSAP/`
-   **Description:** A basic demonstration of the GSAP library for creating high-performance animations. This example shows how to animate multiple elements in a sequence using a timeline.
-   **How to use:** Open the `GSAP/index.html` file in your web browser.

### 3. Lenis (Smooth Scroll)

-   **Folder:** `lenis/`
-   **Description:** An example of how to implement smooth scrolling on a webpage using the Lenis library.
-   **How to use:** Open the `lenis/index.html` file in your web browser and scroll the page.

### 4. Locomotive JS (Smooth Scroll)

-   **Folder:** `Locomotive_Js/`
-   **Description:** This example showcases smooth scrolling and parallax effects using the Locomotive Scroll library.
-   **How to use:** Open the `Locomotive_Js/index.html` file in your web browser and scroll the page.

### 5. ScrollTrigger (with GSAP)

-   **Folder:** `scroll_triger/`
-   **Description:** This example demonstrates how to trigger animations as you scroll down the page using GSAP's ScrollTrigger plugin.
-   **How to use:** Open the `scroll_triger/index.html` file in your web browser and scroll down to see the animations.

### 6. Swiper JS

-   **Folder:** `Swiper/`
-   **Description:** A simple implementation of a carousel/slider using the Swiper.js library. It includes navigation, pagination, and autoplay.
-   **How to use:** Open the `Swiper/index.html` file in your web browser.

### 7. Framer Motion (with React)

-   **Folder:** `Framer_js/`
-   **Description:** A simple React project that uses the Framer Motion library to create animations.
-   **How to use:** 
    1.  Navigate to the `Framer_js` directory.
    2.  Install the dependencies using `npm install`.
    3.  Run the development server with `npm run dev`.

## How to Get Started

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/your-username/Animate_anything_with_sheriyans.git
    ```
2.  **Navigate to a specific example's directory:**
    ```bash
    cd Animate_anything_with_sheriyans/GSAP
    ```
3.  **Open the `index.html` file:**
    Open the `index.html` file from that directory in your favorite web browser to see the example in action.

Feel free to explore, modify, and build upon these examples to create your own amazing web animations!
